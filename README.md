# Triple Ten Art Gallery

![Triple Ten Art Gallery Preview](/images/sprint5.png)

## 📋 Descripción

Triple Ten Art Gallery es una galería de arte en línea que celebra la diversidad cultural y artística de diferentes rincones del mundo. El proyecto presenta una experiencia visual inmersiva con un diseño completamente responsivo que se adapta perfectamente a dispositivos móviles (320px), tablets (768px) y escritorio (1280px).

## 🚀 Características

- Diseño responsivo optimizado para múltiples dispositivos
- Galería de imágenes con Grid Layout moderno
- Tipografía personalizada para una identidad visual única
- Efectos visuales avanzados con sombreados y degradados CSS
- Compatibilidad cross-browser garantizada

## 🛠️ Tecnologías Utilizadas

- **Figma** - Diseño y prototipado de interfaces responsivas
- **HTML5** - Estructura semántica del contenido
- **CSS3** - Estilos avanzados incluyendo:
  - **Normalize.css** - Normalización de estilos entre navegadores
  - **@font-face** - Implementación de fuentes personalizadas
  - **CSS Grid Layout** - Estructuras complejas de filas y columnas
  - **Sombras y degradados CSS** - Efectos visuales modernos

## 🔧 Instalación

1. Clona el repositorio:
```bash
git clone git@github.com:luuzuriaga/web_project_homeland.git
```

2. Navega al directorio del proyecto:
```bash
cd web_project_homeland
```

3. Abre `index.html` en tu navegador preferido o usa un servidor local:
```bash
# Con Python 3
python -m http.server 8000

# Con Node.js (npx)
npx serve
```
